# Skizzenbuch – Zeichnen lernen (Druckvorlage)

Zwei Versionen, A4, schwarz-weiß, für den Ringordner:

| Datei | Druck | Umfang |
|---|---|---|
| `skizzenbuch_beidseitig.pdf` | **beidseitig (Duplex), an der langen Kante spiegeln** | 110 Seiten = 55 Blatt |
| `skizzenbuch_einseitig.pdf` | einseitig | 67 Blatt |

Beidseitige Version:
- Übungs-, Zeichen- und freie Seiten liegen immer auf der Vorderseite, ihre Rückseite bleibt leer.
- Teil-Anfänge liegen immer auf der Vorderseite.
- Der Heftrand (27 mm) ist gespiegelt: vorne links, hinten rechts – also immer auf der Lochseite.

Drucker auf „Tatsächliche Größe / 100 %“ stellen.

Neu erzeugen: `python3 build.py && node render.js` (benötigt Playwright/Chromium).
